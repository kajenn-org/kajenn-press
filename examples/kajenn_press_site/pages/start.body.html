Requirements

Python 3.11 and a local filesystem.

The qualified platform is macOS with Python 3.12.9. The catalog needs a local POSIX filesystem with flock and a private directory owned by the application.

Install

shellkajenn-press
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e '.[dev]'

Run the editorial example

Two sites, a shared template, HTML and Markdown blocks, Italian and English drafts and a second server start, all through the real REST and MCP transports.

shellexamples/editorial.py
python3 examples/editorial.py /tmp/kajenn-press-editorial-demo

Start a loopback server

The server admits one configured administrator with a private token.

shellexamples/serve.py
export KAJENN_PUBLIC_SITE_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')"
python3 examples/serve.py /tmp/kajenn-press-server --port 8080

Create a site

shellREST
curl -sS -H "Authorization: Bearer $KAJENN_PUBLIC_SITE_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"key":"first-site","name":"Example","languages":["it","en"]}' \
  http://127.0.0.1:8080/site_create

List the MCP tools

OpenAPI is at /_meta/schema_json and MCP at /mcp, both with the same authorization header.

shellMCP
curl -sS -H "Authorization: Bearer $KAJENN_PUBLIC_SITE_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' \
  http://127.0.0.1:8080/mcp
