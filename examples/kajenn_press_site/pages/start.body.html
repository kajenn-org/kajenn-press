Requirements

Docker and this repository.

The composition runs the administration with its render worker, RustFS as local S3 storage with versioning, and, with the demo profile, a publisher of this site and a Kajenn site server.

Configure

shellkajenn-press
cp deploy/docker/.env.example deploy/docker/.env

Start

The demo profile publishes this site in English and Italian.

shellDocker Compose
docker compose -f deploy/docker/compose.yaml --profile demo up -d --build

Sign in

The administration is at http://kpress.localhost:8875/admin/ with user operator; its password was generated at the first start.

shellDocker Compose
docker compose -f deploy/docker/compose.yaml exec websites cat /secrets/operator_password

See the site

This site is served at http://press.localhost:8877/, and in Italian under /it/.

Call the operations

OpenAPI is at /_meta/schema_json and MCP at /mcp; the token is in the websites volume.

shellMCP
curl -sS -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' \
  http://kpress.localhost:8875/mcp
